# v2.12.0 — Nota implementasi C025

## Struktur

- `arc11.js` menambah C025 melalui extension points sedia ada: daftar kes, rak Fail Kes, `renderScene()`, pencapaian, watak/lokasi, simpan/pulih dan handler klik berdelegasi.
- `scenes.meaningMapFinale` menggunakan lima hotspot peratusan dan aset WebP tempatan.
- `lensa.js` menambah aktiviti ke-20 tanpa mengubah ganjaran kes.
- `character-presentation.js` mendaftarkan potret kanon Aynaa dan Emah untuk momen watak.
- A32 `Penyatu Makna` dan A33 `Fail Kelima Lengkap` diturunkan daripada rekod sejarah kes; tiada bendera save baharu.

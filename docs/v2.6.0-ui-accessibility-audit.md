# Audit UI dan Kebolehcapaian v2.6.0

## Pembetulan

Pada 360×640, kombinasi logo, Muka Depan dan Bunyi melampaui viewport. CSS telefon kini mengekalkan sasaran 44 px, memaparkan Muka Depan sebagai ikon rumah dengan `aria-label` asal, memadatkan jurang dan memastikan Bunyi kekal kelihatan. Selepas pembetulan, tiada overflow halaman atau kawalan utama terpotong dalam matriks Chrome/Edge.

## Matriks paparan sebenar

| Saiz | Chrome | Edge | Skop |
|---|---|---|---|
| 360×640 | PASS | PASS | header, Agensi, Peta, Pencapaian, Watak, Panduan |
| 390×844 | PASS | PASS | sama + screenshot |
| 430×932 | PASS | PASS | sama |
| 800×450 | PASS | PASS | landskap rendah |
| 1024×768 | PASS | PASS | tablet |
| 1366×768 | PASS | PASS | desktop + screenshot |
| 1600×900 | PASS | PASS | desktop besar |
| 1920×1080 | PASS | PASS | desktop penuh |

Peta menggunakan scroll dalaman yang disengajakan; kawalan di luar potongan semasa berada dalam kanvas boleh ditatal dan tidak dikira sebagai overflow halaman.

## Input dan modal

- Pointer/touch: kad watak, pose, navigasi dan deduksi kes diaktifkan melalui DOM sebenar.
- Keyboard: Enter/Space pada galeri, Tab/Shift+Tab dalam modal, Escape untuk tutup.
- Lensa: overlay viewport, scroll dalaman, kunci latar, perangkap fokus, pemulihan fokus/scroll diuji Chrome/Edge.
- Reduced motion: konteks pelayar menggunakan `reducedMotion: reduce`; tiada kegagalan fungsi.
- Status salah/betul menggunakan teks dan `role=status`, bukan warna sahaja.

## Had

Back/Forward, 125% dan 200% zoom tidak diautomasi dalam pusingan v2.6.0 ini. Tiada pembaca skrin khusus atau audit kontras berinstrumen dijalankan, jadi laporan ini tidak mendakwa pensijilan WCAG 2.2 AA. Peranti fizikal v2.6.0 tidak diuji; penerimaan peranti yang dinyatakan pengguna hanya merujuk baseline v2.5.2.

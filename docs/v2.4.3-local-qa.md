# Detektif Bahasa v2.4.3 — QA tempatan

Status: **PENDING PHYSICAL DEVICE ACCEPTANCE**

## Kegagalan asal

Fail simpanan sebenar diuji terus dari lokasi luaran repositori dan tidak diubah. Simpanan itu memilih `C005`, mempunyai rekod C005 yang sudah selesai bersama run ulangan C005 yang masih berjalan pada scene 1, serta run separa C018 pada scene 3 dengan satu petunjuk.

Sebelum pembaikan, kedua-dua butang Muka Depan wujud, kelihatan dan aktif. Klik penuding sampai kepada butang, tetapi pengendali navigasi Muka Depan tidak dipanggil. Paparan kekal pada Muka Depan tanpa ralat JavaScript.

Punca tepat berada dalam tiga listener klik capture lama di `game.js` untuk C003, C004 dan C005. Apabila `activeCase` ialah salah satu kes tersebut, listener berkenaan menerima semua klik butang lebih awal dan memanggil `stopImmediatePropagation()` sebelum listener navigasi Muka Depan. Simpanan baharu biasanya memilih C001, jadi masalah tidak kelihatan dalam sesi baharu atau Inkognito. Keadaan rekod selesai bersama run ulangan adalah sah dan bukan kerosakan data.

## Pembaikan

Listener capture C003–C005 kini keluar awal apabila `titleOpen` atau `parentOpen` aktif. Tiada butang dibina semula, tiada perubahan pada pemilihan `activeCase`, dan kunci simpanan kekal `detektif-bahasa-v1`.

## QA pelayar sebenar

Edge dan Chrome diuji melalui klik penuding DOM sebenar pada 360×640, 390×844, 800×450, 1366×768 dan 1920×1080.

Pada kesemua sepuluh kombinasi pelayar/viewport:

- Muka Depan memaparkan tepat satu butang Masuk Agensi dan satu butang Sambung Siasatan.
- Ujian hit pada titik tengah butang mengenal pasti tindakan `agency`.
- Masuk Agensi membuka Agensi tanpa menukar C005 atau scene aktif.
- Kembali ke Muka Depan kemudian Sambung Siasatan membuka C005 scene 1.
- Muat semula mengekalkan butang dan destinasi Resume.
- Tiada limpahan mendatar peringkat halaman.
- Tiada ralat halaman atau respons aset aplikasi 4xx/5xx.
- Rekod C001–C018, run C005 dan run C018 kekal sama tepat.

Edge dan Chrome turut lulus pada 390×844 untuk save baharu, C018 separa, save separa rosak dan localStorage yang tidak tersedia. Save separa rosak pulih secara setempat kepada run sah tanpa mengosongkan keseluruhan struktur.

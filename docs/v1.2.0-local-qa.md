# Detektif Bahasa v1.2.0 — QA Setempat

Versi: `v1.2.0 by Zil-el-Saif`

## Skop

Enam latar adegan siasatan dinaik taraf kepada WebP 1600×900: kelas Sekolah Bayuraya, Perpustakaan Bayuraya, Kedai Matematik, Sudut Bacaan, Taman Bayuraya dan Dataran Hari Bayuraya. Semua menggunakan enjin `renderScene()` yang sama. Identiti hotspot, tugas, hint, petunjuk, papan bukti, deduksi, skor, unlock dan save tidak berubah.

SVG lama dikekalkan sebagai rekod/fallback sejarah. Runtime menggunakan WebP baharu dan fallback HTML sedia ada kekal jika imej gagal dimuatkan.

## QA

- Semua hotspot berada dalam julat 0–100 dan tidak bertindih secara bermakna.
- Sasaran sentuh minimum kekal melalui CSS hotspot semantik.
- Tatal dalaman adegan pada telefon kekal; tiada limpahan halaman mendatar.
- Tab, Enter, Space, tetikus dan sentuhan kekal melalui butang HTML.
- Save v1.1.0 menggunakan skema versi 2 dan kunci simpanan yang sama.
- Regresi penuh KES 001–005 lulus tanpa perubahan hasil.

Saiz render QA: 360×640, 390×844, 800×450, 1366×768 dan 1920×1080.

Pemeriksaan: `node --check game.js`, `node --check server.js`, `node test-game.cjs`, `git diff --check` dan HTTP 200 semua aset runtime.

Tiada commit, push, deployment atau QA produksi dibuat.

## Susun Mesej

- Lima cebisan canonical tidak berubah.
- Susunan paparan baharu dikocok untuk setiap run dan disimpan dalam `messageDisplay`.
- Susunan canonical tidak pernah digunakan sebagai paparan awal; perlindungan tambahan memutar susunan jika kocokan menghasilkan 0–4.
- Label A–E merujuk kedudukan paparan dan tidak membocorkan jawapan.
- Folder perlu ditemui sebelum kad susunan dipaparkan.
- Undo, Padam susunan, jawapan salah dan bantuan 0/3–3/3 kekal berfungsi.
- Selepas jawapan betul, hanya ayat lengkap, maklum balas berjaya dan tindakan `Cari Bekas Bahan` dipaparkan. Semakan berulang disekat.

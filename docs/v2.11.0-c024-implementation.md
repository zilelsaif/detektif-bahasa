# v2.11.0 — C024 Implementation

## Architecture

`arc10.js` extends the established case architecture. It reuses:

- the shared percentage-hotspot `renderScene()` engine;
- existing case run/record persistence;
- the guided Evidence Board interaction pattern;
- the standard hint, deduction, replay and historical-best pipelines;
- the v2.10.1 character presentation helpers;
- the existing Lensa Bahasa modal.

No second scene engine, scoring engine or save key was introduced.

## Kanta Konteks

The workspace has three stations and six independent records. A record becomes valid only when all three selections match:

1. a defensible contextual phrase;
2. the intended meaning;
3. the correct visual card.

Multiple defensible phrases are accepted for A1, B2, C1 and C2. A correct meaning with missing context or the wrong picture is explicitly rejected. Completed records generate the restored public display cards from authoritative state.

## Artwork provenance

`assets/locations/dataran-pameran-c024.webp` was generated locally with the built-in image generation tool specifically for this case, then resized to 1600×900 and encoded as WebP. The prompt required a premium bright Malaysian town-square exhibition, five distinct evidence zones, no characters, no readable generated text, no UI and no watermark. All educational text is rendered as accessible HTML.

## Save compatibility

- Key remains `detektif-bahasa-v1`.
- C024 adds only a new per-case run/record object.
- Normalization filters invalid clue IDs, mapping IDs, scene progress and evidence selections.
- Replay and restart reset the C024 run only while preserving its historical best and all older case records.

# Detektif Bahasa v2.4.2 — Title Navigation Rebuild

Tarikh: 16 Oktober 2026  
Status: **LULUS SETEMPAT · PENDING PHYSICAL DEVICE ACCEPTANCE**

## Diagnosis dan skop

v2.4.1 telah membetulkan masa pemulihan save lewat, tetapi dua tindakan utama masih dibina dalam dua renderer berasingan dan dikendalikan oleh listener besar yang turut mengurus kawalan tajuk serta Parent Hub. Ujian automasi v2.4.1 tidak membuktikan penerimaan pada tiga peranti fizikal yang melaporkan kegagalan.

v2.4.2 membuang markup `.title-actions`, atribut `data-title-resume` / `data-title-enter`, fungsi `openTitleDestination()` dan cabang handler lama. Enjin save dan `hasResumableRun()` dikekalkan.

## Komponen baharu

`titleNavigationHtml()` menghasilkan satu panel `<nav class="title-navigation">` dalam aliran biasa, selepas tagline. Panel menggunakan dua tindakan unik:

- `data-title-navigation-action="resume"` — hanya apabila run sah boleh disambung;
- `data-title-navigation-action="agency"` — sentiasa tersedia.

Kedua-duanya ialah `<button type="button">`. Panel mempunyai latar separa legap sendiri, butang teal dan krim, jurang jelas serta sasaran minimum 52–56 px. Pada skrin telefon, butang tersusun menegak. Pada skrin pendek 800×450 atau orientasi mendatar, butang menggunakan dua lajur supaya kedua-duanya kekal dalam viewport.

Latar, shade dan KLU kekal berasingan serta tidak menerima pointer events. Tiada peningkatan z-index global atau kawalan berposisi tetap ditambah.

## Kitar hayat input

Satu listener delegasi khusus dipasang pada `#app` yang stabil. Ia hanya menerima `resume` atau `agency`, mengesahkan semula run ketika diaktifkan dan menggunakan pengadang satu tindakan untuk mencegah navigasi berganda. Rerender tidak menggantikan atau menggandakan listener.

Jika tindakan resume menjadi tidak sah antara render dengan pengaktifan, Agensi dibuka dan mesej berstatus menerangkan bahawa fail kes perlu dipilih semula. Masuk Agensi tidak mengosongkan kes atau stage aktif.

## Save dan cache

- Kunci kekal `detektif-bahasa-v1`.
- Fresh save dan save separa C001, C006, C015, C016, C017, C018 serta C019 diuji.
- Bentuk save rosak dan localStorage tidak tersedia kekal menggunakan perlindungan v2.4.1.
- Title, footer, metadata dan constant menggunakan `v2.4.2 by Zil-el-Saif`.
- CSS dan tujuh fail JavaScript menggunakan `?v=2.4.2`.
- Tiada service worker atau PWA baharu ditambah.
- Production tidak diperiksa atau diubah.

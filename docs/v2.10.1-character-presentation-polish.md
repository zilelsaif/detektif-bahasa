# v2.10.1 — Character Integration & Presentation Polish

## Scope

This local-only presentation pass integrates the existing official Bayuraya character assets into KES 022 and KES 023. It does not change case content, clue logic, rewards, progression, achievements, or the `detektif-bahasa-v1` save key.

## Folder naming

- The fifth case-folder label is exactly `FAIL KELIMA`.
- `Jejak Makna Bayuraya` remains the story/arc title and is rendered separately inside the folder panel.
- C021, C022, and C023 remain the only available entries; C024–C025 remain upcoming.

## Presentation behavior

- `character-presentation.js` centralizes asset mapping and three stateless render helpers.
- Source documents and pre-deduction moments use compact mugshot dialogue cards.
- Completed editor state may use a two-character moment card.
- Resolution screens use an editorial grid: the approved environment is shown as a complete image, while official full-body poses sit in separate `object-fit: contain` cards. This avoids fake compositing, crop loss, and incorrect character scale.
- Mobile stacks the environment above the two pose cards; desktop uses environment and cast columns.

All presentation is derived from existing case state. No new persistent fields were added.

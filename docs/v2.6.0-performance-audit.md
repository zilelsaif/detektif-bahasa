# Audit Prestasi v2.6.0

## Ukuran setempat

Diukur daripada fail kerja pada 20 Oktober 2026, tanpa simulasi rangkaian produksi:

- 149 aset dalam `assets/`.
- Saiz aset keseluruhan: 12,564,509 bait (11.98 MiB).
- HTML/CSS/JS/server runtime: 554,827 bait (541.8 KiB), sebelum pemampatan HTTP.
- Tiada pasangan aset yang serupa bait demi bait berdasarkan SHA-256.
- Data penuh: `docs/v2.6.0-performance-data.json`.

Aset terbesar ialah poster sokongan (1,789,080 bait), diikuti scene Taman Bayuraya (485,314), peta Bayuraya (433,298), pondok aktiviti (379,866) dan poster siap C018 (354,856). Aset ini bukan semuanya dalam laluan awal yang sama; kebanyakan imej kes diminta apabila skrin berkaitan dirender.

## Kod dan rangkaian

Aplikasi kekal tanpa framework dan tanpa permintaan aset jauh. Urutan skrip ialah `mechanics.js`, `game.js`, `arc2.js`, `arc3.js`, `arc4.js`, `arc5.js`, `arc6.js`, `lensa.js`, `character-gallery.js`. Saiz JS terbesar ialah `game.js` dan `arc5.js`; struktur override berlapis menambah kos penyelenggaraan tetapi perubahan besar berisiko tinggi dan tidak sesuai untuk audit ini.

Server setempat menyediakan MIME aset dan fail tempatan. Tiada dependency runtime pihak ketiga pada klien. Rendering menggunakan penggantian HTML skrin, jadi pertukaran kes membina semula DOM; ujian berulang tidak menunjukkan exception atau pertambahan listener yang memecahkan input.

## Dapatan

Tiada P1 prestasi yang boleh diulang. Poster sokongan ialah calon pengoptimuman muatan jika dimuat pada laluan awal, tetapi ia kandungan Parent Hub yang dilindungi dan tidak diubah tanpa bukti visual setara. Tiada aset dipadam kerana carian teks sahaja tidak cukup membuktikan aset tidak digunakan secara dinamik.

Profil FPS, penggunaan memori peranti dan decoding pada Kyocera Torque KYG03/Galaxy Tab Active 3 **TIDAK DIUJI** dalam pusingan ini. Bukti ini ialah ukuran fail dan ujian Chrome/Edge desktop setempat, bukan jaminan 60 FPS atau prestasi produksi.

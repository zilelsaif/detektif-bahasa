# Detektif Bahasa v2.4.1 — Title Screen Reliability QA

Tarikh: 15 Oktober 2026  
Status: **LULUS SETEMPAT · BELUM DI-COMMIT / PUSH / DEPLOY**

## Diagnosis

Audit hit-testing awal tidak menemui overlay yang menghalang kawalan. Pada 360×640, 390×844, 800×450, 1366×768 dan 1920×1080:

- `document.elementFromPoint()` di pusat kedua-dua butang mengembalikan butang sebenar;
- `pointer-events` ialah `auto`;
- tinggi butang ialah 52–56 px;
- parent tiada transform atau stacking context yang menghalang;
- tetikus, sentuhan, Enter dan Space sampai kepada handler.

Punca sebenar ditemui pada refresh save daripada arc kemudian. `game.js` merender skrin tajuk sebelum `arc2.js` hingga `arc5.js` selesai memulihkan `activeCase`. Sebagai contoh, save C019 dipulihkan dengan betul secara dalaman, tetapi markup tajuk masih dibina daripada keadaan C001 awal. `hasResumableRun()` kemudian bernilai benar sedangkan butang **SAMBUNG SIASATAN** tidak wujud pada markup yang kelihatan.

Satu kegagalan berasingan turut ditemui: JSON yang sah tetapi mempunyai bentuk `cases` tidak sah, seperti `{"cases":"broken"}`, menghentikan pemulaan JavaScript.

Tiada bukti bahawa `z-index` ialah punca. Nilai z-index tidak dinaikkan secara rawak.

## Hotfix

- Struktur top-level save dan setiap entri kes disahkan sebelum digunakan. Entri yang rosak tidak menimpa rekod lain yang masih sah.
- Kunci kekal `detektif-bahasa-v1`; tiada reset atau migrasi save penuh.
- Skrin tajuk dirender sekali lagi selepas semua arc selesai memulihkan kes aktif.
- `openTitleDestination()` memeriksa semula sama ada run masih boleh disambung ketika butang diaktifkan. Jika tidak, ia membuka Agensi dengan selamat.
- Listener delegasi kekal satu kali dan render berulang tidak menghasilkan handler pendua.
- Event `pageshow` yang dipulihkan daripada back-forward cache merender semula keadaan semasa.
- Semua butang tajuk menggunakan `type="button"`.
- Lapisan latar, shade dan KLU dekoratif menggunakan `pointer-events:none`; ini ialah perlindungan eksplisit dan tidak mengubah susun atur.
- CSS dan tujuh fail JavaScript utama menggunakan query keluaran `?v=2.4.1`, supaya HTML v2.4.1 tidak memuat runtime versi terdahulu daripada cache.
- Versi dikongsi melalui `RELEASE='v2.4.1 by Zil-el-Saif'`; tajuk, footer, metadata dan `data-release` sepadan.

## Browser dan input QA

Microsoft Edge dan Google Chrome sebenar dikawal melalui Playwright terhadap server setempat. Kedua-duanya lulus aliran **MASUK AGENSI**, refresh save separa C019, paparan **SAMBUNG SIASATAN** dan pengaktifan melalui Enter pada 390×844. Firefox dipasang, tetapi binaan Firefox biasa tidak menyediakan protokol `juggler` yang diperlukan oleh Playwright dan tidak dapat diautomasi dalam persekitaran ini.

| Viewport | Pusat hit tepat | Mouse/touch | Enter/Space | Tiada overflow |
| --- | --- | --- | --- | --- |
| 360×640 | Lulus | Lulus | Lulus | Lulus |
| 390×844 | Lulus | Lulus | Lulus | Lulus |
| 800×450 | Lulus | Lulus | Lulus | Lulus |
| 1366×768 | Lulus | Lulus | Lulus | Lulus |
| 1920×1080 | Lulus | Lulus | Lulus | Lulus |

Turut lulus:

- refresh dengan partial C019 memaparkan **SAMBUNG SIASATAN** dan kembali ke scene 4;
- perubahan orientasi 390×844 → 844×390;
- kembali melalui browser history/back-forward cache;
- **MASUK AGENSI** berfungsi ketika run aktif wujud;
- kedua-dua butang berfungsi secara bebas;
- tiada pengecualian JavaScript dalam semua fixture di atas.

## Cache dan versi

Sumber tempatan sebelum hotfix ialah v2.4.0. Screenshot produksi yang menunjukkan v2.0.0 sepadan dengan keadaan produksi yang belum menerima keluaran tempatan v2.4.0. Ia bukan bukti bahawa footer tempatan v2.4.0 rosak.

Production tidak diperiksa kerana arahan melarang Cloudflare production QA. Query keluaran v2.4.1 mengurangkan risiko HTML baharu bercampur dengan CSS/JS lama selepas deployment akan datang. Tiada service worker ditemui dan tiada PWA/cache system baharu ditambah.

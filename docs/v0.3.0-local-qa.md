# v0.3.0 — Perpustakaan Bayuraya Interactive Scene

Tarikh QA setempat: 24 September 2026.

## Pelaksanaan

- `scenes.library` menggunakan enjin `renderScene()` yang sama dengan kelas. Tiada renderer, pendengar klik atau sistem hotspot kedua.
- Babak menyimpan ID, aset SVG setempat, nisbah 16:9, label lokasi dan tujuh hotspot berkoordinat peratus: `rak buku`, `kotak pemulangan`, `papan kenyataan`, `meja membaca`, `pustakawan`, `kaunter`, dan `beg perpustakaan`.
- Aliran perpustakaan ialah cari beg merah → cari pustakawan → dialog sedia ada → latihan “menyerahkan”. Menemui beg dan pustakawan tidak mengubah kiraan petunjuk. Latihan pustakawan kekal satu-satunya sumber petunjuk 5.
- Kemajuan dua tindakan perpustakaan disimpan dalam medan pilihan `sceneProgress`. Save v0.2.0 tanpa medan itu masih dibuka melalui nilai lalai, dan save lama dengan `libraryEntered` terus membuka dialog pustakawan.
- Jika SVG gagal, hotspot berlabel kekal di atas fallback. Jika data scene tiada, kawalan sasaran berlabel masih membolehkan aliran diteruskan.

## Bantuan dan input

- Beg merah dan pustakawan masing-masing mempunyai bantuan 0/3 hingga 3/3: teks, penekanan kawasan, kemudian penekanan sasaran dengan label.
- KLU menggunakan `thinking` untuk pilihan salah, `hint` untuk bantuan dan `excited` untuk pilihan betul.
- Semua hotspot ialah `button` dengan `aria-label`, fokus kelihatan, dan sokongan Tab, Enter, Space, tetikus serta sentuhan.
- Tatal mendatar asli diuji pada 390 px. Nilai tatal berubah daripada 0 kepada 216 px tanpa memilih hotspot atau mengubah langkah 1/2.

## Aliran penuh dan regresi

Aliran setempat diselesaikan: halaman utama → surat → kelas interaktif → beg → kerusi → nota → Aynaa → Hakim → Mei Ling → Perpustakaan Bayuraya → beg merah → pustakawan → “menyerahkan” → 5/5 → papan bukti → deduksi → KES 001 SELESAI → replay.

Disahkan:

- pilihan salah dan bantuan 0/3–3/3 berfungsi dalam kedua-dua scene;
- kelas masih menggunakan koordinat, urutan, fallback dan kawalan sedia ada;
- beg perpustakaan tidak menaikkan kiraan daripada 4/5;
- jawapan salah “membaca” ditolak dan “menyerahkan” menghasilkan tepat 5/5;
- papan bukti tidak menerima sambungan kosong dan menerima tiga sambungan betul;
- teori salah ditolak dan teori akhir kekal sama;
- refresh selepas beg ditemui memulihkan langkah “Cari pustakawan”;
- refresh selepas pustakawan ditemui memulihkan latihan bahasa;
- Bunyi: Mati kekal selepas refresh, kemudian boleh dihidupkan semula;
- Fail Kes, navigasi Agensi dan replay berfungsi; rekod terbaik kekal selepas replay;
- log pelayar tidak mengandungi ralat JavaScript.

## Ujian automatik dan prestasi

Lulus:

- `node --check game.js`
- `node test-game.cjs`
- `git diff --check`

Ujian automatik meliputi kewujudan `scenes.library`, ID dan julat koordinat, pertindihan, sasaran beg/pustakawan, pilihan salah, kedua-dua set bantuan, kiraan 5 petunjuk, regresi kelas, fallback, refresh, save lama, papan bukti, deduksi, replay dan bunyi.

`assets/locations/library-bayuraya.svg` bersaiz 4,845 bait. Tiada dependency, framework, Canvas, pustaka animasi atau aset jauh ditambah.

## Batasan dan cadangan

Pada telefon, bahagian kanan babak termasuk beg memerlukan leretan mendatar; panduan “Leret ke sisi” dan tatal asli dikekalkan untuk sasaran sentuh yang besar. Ujian sentuhan fizikal pada peranti sebenar tidak dibuat dalam sesi ini.

Cadangan versi seterusnya: uji kedua-dua scene pada peranti sentuh fizikal dan kumpulkan pemerhatian pemain tentang kebolehcarian beg serta pustakawan sebelum menambah lokasi atau kes baharu.

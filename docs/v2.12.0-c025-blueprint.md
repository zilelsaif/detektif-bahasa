# v2.12.0 — C025 Implementation Blueprint

## Canonical scope

- Case: C025 — Misteri Peta Jejak Makna.
- Arc: Fail Kelima — Jejak Makna Bayuraya.
- Location: Dataran Bayuraya during the closing preparation for Jelajah Bahasa Bayuraya.
- Cast: Aynaa, Cikgu Farah, Emah and KLU.
- Completion target: 5 clues, 4 stations, 8 educational validations, 3 evidence relationships, 4-slot map assembly and 2 deductions.

## Five official sources

1. P1 Ringkasan Sukarelawan — establishes that `ringan tulang` means rajin membantu.
2. P2 Senarai Prop Disahkan — confirms batang, helai, keping, utas and pasang by object form.
3. P3 Panduan Ejaan Jelajah Bahasa — confirms `atur cara`, passive `diadakan`/`dijemput`, and locative `di ruang legar`/`di sini`.
4. P4 Legenda Pameran Makna — confirms calendar-month `bulan` and competition-points `mata` through sentence context and visuals.
5. P5 Peta Jejak Makna Bayuraya — an explicitly unverified draft containing the four station problems and route A → B → C → D.

Sources can be opened in any order. Their readable content is HTML; the premium scene only supplies recognizable physical objects and spatial context.

## Peta Makna stations and eight validations

| Station | Skill | Validations | Required proof | Verified output |
| --- | --- | ---: | --- | --- |
| A — Jejak Kiasan | Simpulan bahasa | 1 | P1 + P5 | Ringan tulang bermaksud rajin membantu atau bekerja. |
| B — Jejak Bilangan | Penjodoh bilangan | 2 | P2 + P5 | Bahan stesen: dua batang pensel dan seutas tali. |
| C — Jejak Ejaan | Ejaan standard | 3 | P3 + P5 | Atur cara penutup akan diadakan di ruang legar. Peserta dijemput berkumpul di sini. |

Stations remain visitable before proof is collected, but verification explains the missing source instead of silently disabling interaction. Station completion is derived from its validation records, so booklet content and final readiness cannot diverge.

## Guided Evidence Board

- EB-01: P5 + P1 + P2 prove that draft descriptions conflict with official information.
- EB-02: P3 + P4 + P5 prove that instructions and meanings require language rules and sentence context.
- EB-03: all five sources + all four stations + both earlier links prove the final guide is ready.

One relationship is verified at a time with named evidence cards, recoverable wrong feedback and persisted link state.

## Final map assembly

Four numbered slots follow P5's route A → B → C → D. The player selects a slot and then a verified station card; duplicate or incomplete assignments cannot pass. Incorrect placements can be changed without resetting station work. Success creates the authoritative `mapVerified` state and unlocks the booklet preview.

## Two deductions

1. D01: the draft is confusing because several descriptions use inaccurate language or interpretation.
2. D02: publication requires four accurate descriptions, suitable proof and a complete map order.

Completion uses one readiness predicate covering P1–P5, all eight validations, all four station states, the three evidence links, verified map assembly and both deductions.

## Finale and booklet

- `Buku Jejak Makna Bayuraya` is an in-game HTML booklet with cover, four verified learning sections and a final KLU page.
- It unlocks only after valid case completion and never grants XP, stars, clues or achievements when reopened.
- The resolution uses one integrated 1600×900 WebP featuring Aynaa, Cikgu Farah and Emah in the completed Dataran event; KLU remains available through the established companion UI.
- The investigation uses a separate 1600×900 premium Dataran scene with five visible source objects and four themed activity zones.

## Achievements and scoring

- Maximum: 650 XP and 5 stars through the established hint-penalty pipeline.
- A32 Penyatu Makna: historical C025 completion.
- A33 Fail Kelima Lengkap: valid historical records for C021–C025.
- Expected aggregate after a perfect complete save: 25 cases, 125 official clues, 33 achievements, 20 Lensa activities, 109 maximum stars and 9,870 maximum historical-best XP.

## Save model

The existing `detektif-bahasa-v1` schema is retained. C025 stores only its run/record data: scene, clues, opened source, station selections and validations, evidence selections/links, map slots/verification, hint levels, attempts, deductions, completion and resolution state. The booklet and achievements are derived from historical completion; no duplicate permanent unlock flags are required.

Normalization clamps arrays, IDs and scene values so malformed or older saves recover safely. Replay resets only the C025 run and preserves its best record plus all C001–C024 data.

## Blocker pemain

Pemain mencapai KES 006 pada 5/5 petunjuk tetapi tidak dapat melepasi “Sambungkan bukti”. Bug berjaya direproduksi daripada state papan bukti dan fixture save v1.8.0.

## Punca tepat

`renderSecondEvidence()` menghasilkan dropdown dengan atribut `data-second-link`, tetapi Fail Kedua tidak mendaftarkan pengendali `change` untuk atribut tersebut. Pilihan berubah pada elemen `<select>` sahaja dan tidak pernah disalin ke `state.links`. Apabila “Semak sambungan” ditekan, validator membaca empat nilai kosong. Ujian lama tidak mengesan masalah ini kerana ia mengisi `state.links` terus melalui JavaScript dan tidak menghantar event dropdown sebenar.

Satu isu pemulihan berkaitan turut ditemui oleh fixture: save dengan `activeCase=C006` boleh cuba dirender oleh `game.js` sebelum `arc2.js` dimuat. Pemulihan C006–C010 kini ditangguhkan sehingga modul Fail Kedua tersedia, sama seperti pemulihan C011–C014.

## Sebelum dan selepas

Sebelum:

- empat baris generik PETUNJUK 1 → PETUNJUK 5;
- petunjuk pengecualian dipaksa ke rantai bersebelahan;
- dropdown tidak mengemas kini state;
- validator tidak boleh berjaya melalui UI.

Selepas:

1. KAD PESANAN → **diletakkan di sebelah** → DULANG BIRU
2. DULANG BIRU → **dipindahkan ke** → RAK PENYEJUK
3. KAD PESANAN → **ditemui di bawah** → DULANG BIRU
4. PEMBANTU PENGHANTARAN → **tidak mengambil** → KAD PESANAN

Tiga baris pertama menerangkan perjalanan kad. Baris keempat kekal sebagai bukti sokongan/pengecualian dan tidak dipaksa menjadi hubungan kausal palsu.

## Penerimaan C006

- State 5/5 dan papan bukti dipulihkan tanpa reset.
- Event `change` sebenar mengemas kini dan menyimpan setiap pilihan.
- Konfigurasi salah gagal dengan mesej: “Hubungan itu belum menerangkan perjalanan kad. Semak semula petunjuk.”
- Semak Petunjuk menunjukkan kelima-lima petunjuk dan tidak membersihkan pilihan dropdown.
- Hubungan sah mengaktifkan langkah deduksi.
- Deduksi asal kekal: kad bergerak bersama dulang biru dan terselit di bawahnya pada rak penyejuk.
- C006 selesai dengan ganjaran asal 4 bintang / 250 XP maksimum.
- Rekod sejarah C006 dan buka kunci C007 kekal selepas replay atau Mulakan Semula Kes.

## Keserasian save lama

Fixture v1.8.0 mengandungi `activeCase=C006`, `scene=6`, `cluesFound=5`, petunjuk 1–5 selesai dan kes belum lengkap. Fixture dimuat dalam v1.8.1, papan dirender, hubungan dipilih melalui event UI, validator lulus dan state bergerak ke scene deduksi tanpa restart.

Nilai hubungan lama yang tidak lagi sepadan tidak merosakkan save; dropdown boleh dipilih semula dan disimpan. Clue, cubaan, rekod serta kes lain tidak dipadam.

## Responsif

Struktur papan bukti menggunakan `.connections` dan `.connection` sedia ada. Pada lebar maksimum 650px, setiap baris bertukar kepada susunan menegak, dropdown mempunyai `max-width:100%`, dan semua `select` mengekalkan ketinggian kawalan minimum 48px. Ini meliputi 360×640, 390×844 dan 800×450 tanpa menambah tatal mendatar. Layout desktop kekal pada 1366×768 dan 1920×1080.

Automasi pelayar penuh tidak tersedia dalam persekitaran ini kerana Playwright/Puppeteer tiada. Penerimaan wajib dijalankan melalui render DOM sebenar dalam harness, event `change`, state `localStorage`, handler runtime dan pemeriksaan CSS responsif. Tiada dakwaan automasi pelayar penuh dibuat.

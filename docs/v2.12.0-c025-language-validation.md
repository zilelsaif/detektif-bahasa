# v2.12.0 — Validasi bahasa C025

Tarikh semakan: 4 November 2026  
Skop: kandungan `Misteri Peta Jejak Makna`, Buku Jejak Makna dan Lensa Bahasa C025.

## Dapatan

| Kandungan | Keputusan | Rujukan |
|---|---|---|
| `ringan tulang` | Tepat: rajin bekerja / tangkas. | PRPM, entri `ringan` dan khidmat nasihat DBP |
| `atur cara` | Tepat dan dieja terpisah sebagai kata majmuk. | PRPM, entri `atur cara`; DBP turut menolak bentuk `aturcara` |
| `batang` untuk pensel | Tepat untuk benda panjang. | PRPM, entri penjodoh bilangan / `batang` |
| `utas` untuk tali | Tepat untuk benda berurai seperti tali, benang dan rantai. | PRPM, entri `utas` |
| `mata` | Tepat mengikut konteks: organ penglihatan atau markah pertandingan. | PRPM, entri `mata` |
| `bulan` | Tepat sebagai satelit semula jadi bumi dalam konteks sains. | PRPM, entri `satelit` dan khidmat nasihat DBP |
| `diadakan` / `di ruang legar` | Dikekalkan: awalan pasif `di-` dirapatkan, kata sendi `di` diasingkan daripada tempat. | Prinsip ejaan yang digunakan konsisten dengan kandungan kes terdahulu |

## Keputusan editorial

Tiada nilai jawapan C025 perlu diubah selepas semakan. Penerangan dalam permainan sengaja ringkas dan mesra kanak-kanak, tetapi tidak mengubah makna kamus. Teks sumber, pilihan salah dan maklum balas dibezakan dengan jelas supaya pilihan salah tidak dibaca sebagai fakta.

# Detektif Bahasa v1.1.0 — QA Setempat

Versi: `v1.1.0 by Zil-el-Saif`

## Skop

- Muka Depan baharu menggunakan latar Bayuraya setempat dan aset KLU runtime sedia ada.
- CTA diterbitkan daripada run aktif: Masuk Agensi untuk save baharu/ark lengkap, atau Sambung Siasatan bagi run aktif yang boleh disambung.
- Ruang Ibu Bapa memaparkan kemajuan kes, lokasi, watak dan bintang melalui helper sedia ada.
- Poster QR sumber disalin tanpa crop, recolor, recompression atau perubahan modul.
- Reset memerlukan paparan amaran dan pengesahan kedua, lalu menetapkan semula hanya data Detektif Bahasa.
- A01–A09 menggunakan sembilan lencana WebP setempat; syarat pencapaian tidak berubah.

## Keserasian

Skema save kekal versi 2 dan kunci `detektif-bahasa-v1` kekal. Save v1.0.0 memuatkan rekod, bunyi, kes aktif, Peta, Pencapaian dan Watak seperti sebelumnya. Muka Depan dan Ruang Ibu Bapa tidak menyimpan data kemajuan pendua.

## Input dan aksesibiliti

Semua kawalan ialah butang semantik dengan fokus kelihatan dan sasaran praktikal sekurang-kurangnya 44px. Akses Ibu Bapa menggunakan tahan dua saat untuk pointer, dengan Enter/Space sebagai alternatif papan kekunci. Fullscreen menggunakan API pelayar dan disembunyikan apabila tidak disokong. Status lencana mempunyai teks Dicapai/Belum dicapai dan tidak bergantung pada warna.

## QA responsif

Disahkan secara render pada 360×640, 390×844, 800×450, 1366×768 dan 1920×1080 untuk Muka Depan, Ruang Ibu Bapa dan Pencapaian. Semakan merangkumi limpahan halaman, keterlihatan CTA, kedudukan KLU, poster QR tanpa crop serta grid lencana terkunci/dicapai.

- `git diff --check`

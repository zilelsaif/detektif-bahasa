# v2.8.1 — C021 Corrective Pass: Navigation, Visual dan Papan Bukti

## Punca folder pendua

`arc7.js` telah menambah Fail Kelima ke `caseArcDefinitions`, yang merupakan registri kanonik untuk akordion. Pada masa yang sama, fail itu membungkus `caseShelf()` dan menyuntik satu lagi kumpulan Fail Kelima secara manual. Render kanonik menghasilkan folder kosong kerana pengumpul kad lama tidak mengenali C021; wrapper kemudian menghasilkan folder kedua yang mengandungi kad C021.

Pembetulan memperkenalkan `caseArcCardProviders`, iaitu registri kad berdasarkan ID kes. C020 dan C021 mendaftarkan penyedia kad masing-masing. `caseShelf()` kini membina setiap panel terus daripada `arc.ids`, jadi satu ID ark menghasilkan tepat satu folder dan satu kad tanpa perbandingan label atau manipulasi DOM selepas render.

## Papan Bukti Berpandu

Papan lama berasaskan dropdown diganti dengan tiga hubungan berurutan. Setiap hubungan meminta pemain memilih kad bukti, menyemaknya dan menerima maklum balas kontekstual. Kesimpulan hanya dipaparkan selepas hubungan disahkan.

Panduan UI menerangkan empat langkah penggunaan dan tidak menambah `hintsUsed`. Bantuan KLU kekal berperingkat 1–3 serta menggunakan penalti skor sedia ada. Hubungan yang selesai dan pilihan semasa disimpan dalam rekod larian C021 serta dipulihkan selepas refresh.

Hubungan kanonik tidak berubah:

1. Nota Sukarelawan + Catatan Tugasan + KK-01 → makna rajin bekerja.
2. Nota Sukarelawan + Catatan Tugasan + Album Aktiviti → R-03 → Pak Rahim.
3. Kad Meja Sambutan + Rekod Barang + KK-02 → oleh-oleh daripada perjalanan.

Deduksi akhir kekal dikunci sehingga kelima-lima petunjuk, kedua-dua Kanta Kiasan dan ketiga-tiga hubungan selesai.

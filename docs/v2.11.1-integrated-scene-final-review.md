# v2.11.1 — Integrated Scene Final Review

## Method used

All three final resolution scenes were regenerated with the built-in image-generation editor in reference-guided identity-preservation mode. Each generation call received the clean approved environment as the first real image input plus the official mugshot and full-body pose for both required characters as four additional real image inputs.

The C015 environment was inspected separately as the accepted visual-storytelling reference. It was not passed to the generation call because the tool accepts at most five reference images; identity accuracy was prioritized by retaining both official references for each character. The final results are newly rendered unified scenes—not transparent sprites placed over completed backgrounds.

Generated PNG candidates were visually inspected, resized to exactly 1600×900 with Lanczos resampling, and encoded as optimized WebP. Original investigation backgrounds and canonical character files remain untouched.

- Resolution HTML renders only the unified final WebP; no additional pose overlays are added.

## Generation prompts

The three prompts used the same production constraints: redraw the entire environment and characters as one scene; preserve the approved architecture and canonical identity; require natural floor/chair contact, plausible anatomy, matched lighting and perspective; prohibit sticker outlines, floating characters, duplicate limbs, extra people, UI and watermarks. Scene-specific direction covered the C022 checklist/shoes interaction, C023 seated booklet review, and C024 exhibition-card presentation.

## Pengesahan teknikal

- Semua fail: WebP 512×512.
- Semua fail: `yuva420p` dengan saluran alpha.
- Tiada aset jauh atau dependency runtime baharu.
- Galeri menggunakan `loading="lazy"` dan `decoding="async"`.
- Potret aktif sahaja dimuatkan di luar galeri.
- Nisbah dimensi eksplisit mencegah layout shift.
- Kegagalan imej menyembunyikan imej rosak dan memaparkan simbol Lensa.

## Risiko keserasian

Risiko utama ialah validasi metadata lama yang hanya mengenali enam simbol. Ia ditangani dengan satu senarai gabungan 18 ID sambil mengekalkan keenam-enam ID klasik tanpa perubahan. ID tidak sah tetap jatuh kepada `lensa`; bacaan metadata rosak tidak menulis semula registri secara automatik.

## Cross-game findings

- **Clues:** all 15 official clue lists contain exactly five entries. C015 has its own clue review and restart handlers; all cases remain at 0/5, partial and 5/5 boundaries without awarding clues for ordinary scene exploration.
- **Progression:** case order is C001–C015; C006 follows C005, C011 follows C010 and C015 follows C014. No C016 or fourth arc appears. The aggregate caps remain 15 cases, 12 locations, 22 characters, 21 achievements, 63 stars and 4500 maximum best XP.
- **XP caps:** the First Arc max XP values were previously encoded only in completion logic and fixtures. They are now exposed as metadata (150, 170, 190, 210 and 250), matching existing no-hint results. The 10 later cases already declare their caps. All 15 metadata caps add to 4500; award logic and player rewards are unchanged.
- **Evidence and deduction:** the regression suite checks semantic evidence connections and validates incomplete/wrong links before deduction. Wrong theories remain retryable.
- **Hints and review:** hint progression, representative 0/3–3/3 states, discovered-only clue review and save/resume paths are covered by the existing test suite.
- **Restart/replay:** case-level restart preserves historical records and other cases; replay retains best results. Full-progress reset still preserves the sound preference and clears the case records as designed.
- **Saves:** the v1 save key remains `detektif-bahasa-v1`. Existing migration/recovery fixtures for earlier saves and partial runs pass. No schema migration was introduced.
- **Accessibility fix:** clue-review and case-restart dialogs now trap forward and reverse Tab navigation within the active dialog, retain Escape-to-close behavior, and restore focus to the opening control. Mouse/touch interaction is unchanged.
- **Source before question:** regressions explicitly assert the C010 and C015 source/briefing ordering and C015's reference cards before symbol matching. Other case tasks were checked through their authored task/source data and existing per-case flow tests.
- **Runtime assets:** 83 files total, 5.50 MB WebP, 1.71 MB support PNG and 0.05 MB SVG (7.26 MiB / 7.62 MB decimal total). Largest assets are the support poster (1,789,080 bytes), Taman Bayuraya WebP (485,314 bytes), map WebP (433,298 bytes), and Dataran Hari Bayuraya WebP (314,076 bytes). Largest application script is `game.js` (148,782 bytes), followed by `arc3.js` (64,140), `arc2.js` (43,820), `arc4.js` (24,438) and `mechanics.js` (7,253). The poster is a parent-facing QR asset and was left untouched. No asset was recompressed or removed.
- **Hotspots:** every scene's percentage hotspot bounds are within 0–100 and the automated audit found no pairwise hitbox overlap. Existing case-specific DOM-to-object alignment was preserved; percentage checks cannot prove the drawn object beneath each target.
- **HTTP routes:** all 48 statically discoverable runtime asset references exist locally and are present in the local server route table. Dynamic achievement routes are provided by the existing generated route mapping.

## Items intentionally unchanged

The generic opening copy for several Second Arc cases is brief, but each case title, location and first task provide the case context. No source-before-question failure was reproduced in the automated paths, so case prose and pacing were left unchanged. Existing case-specific hotspot geometry and story relationships were preserved; only automated percentage bounds/non-overlap checks and representative rendered checks support this audit. A full human visual review of all hotspot/background pairs remains a recommended follow-up if any player reports a mismatch.

No external deployment, production URL, commit or push was used for this audit.

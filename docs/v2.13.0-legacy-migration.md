# v2.13.0 — Migrasi Simpanan Legacy

## Sumber

Sumber migrasi ialah snapshot `detektif-bahasa-v1`. Ia hanya dianggap boleh dipindahkan apabila berbentuk objek permainan yang sah. Kunci sumber tidak pernah dipadam atau ditulis semula.

## Proses dua fasa

1. Registri merekodkan `pending` menggunakan ID stabil `legacy-detektif-asal`.
2. Snapshot penuh disalin kepada sampul profil, termasuk medan yang tidak dikenali oleh versi semasa.
3. Sampul dibaca semula.
4. Snapshot hasil bacaan dibandingkan secara mendalam dengan sumber.
5. Hanya selepas padanan penuh, `Detektif Asal` ditambah kepada registri dan status menjadi `complete`.

Jika pelayar ditutup, kuota habis atau penulisan gagal, cubaan berikutnya menggunakan ID pending yang sama. Oleh itu migrasi boleh diulang dan tidak menghasilkan profil pendua.

## Audit integriti

Fixture acceptance mengandungi `activeCase: C025`, rekod C001, kemajuan C025, pilihan bunyi, Lensa Bahasa dan medan masa hadapan yang tidak dikenali. Perbandingan mendalam sebelum/selepas migrasi lulus. Ujian tambahan mengesahkan tiga profil dengan keadaan berpengalaman, baharu dan separa kekal terasing selepas pertukaran dan penulisan.

## Pemulihan

- Jika migrasi belum lengkap: ulang langkah menggunakan ID stabil.
- Jika profil individu rosak: kekalkan data mentah dan sekat penulisan automatik.
- Jika revisi berubah: jangan gabungkan secara senyap; muat semula profil terbaru.
- Sandaran legacy sentiasa kekal untuk pemulihan manual.

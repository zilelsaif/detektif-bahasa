# v0.1.2 — Visual North Star Integration

## Pelaksanaan
- Hierarki desktop: KLU | panel kes utama | Fail Kes; navigasi sekunder di bawah.
- Panel krim dengan bingkai teal, tab amber, beg merah, ⭐ Jejak Awal dan potret kecil Aynaa.
- KLU ialah SVG asli setempat, burung hantu teal/krim dengan mata amber dan beg kecil. Pemain kekal detektif utama.
- Bayuraya menggunakan ilustrasi SVG bandar yang ringan. Palet utama ditakrifkan sebagai pemboleh ubah CSS.
- KES 002–005 dikunci tanpa tajuk atau permainan baharu. Navigasi masa hadapan dilabel Akan datang dan dinyahaktifkan.
- Semua fon/aset permainan setempat. Imej North Star disalin ke docs/detektif-bahasa-north-star.png sebagai rujukan sahaja, tidak dipotong atau digunakan sebagai latar.
- Footer: v0.1.2 by Zil-el-Saif.

Tiada limpahan mendatar, aset rosak atau pemotongan teks oleh overflow tersembunyi ditemui. Kandungan panjang boleh ditatal secara menegak, termasuk pada telefon dan landskap pendek. Dimensi diperiksa melalui innerWidth/innerHeight selepas mengambil kira penskalaan paparan.

Aliran penuh pelayar pada localhost:4173: halaman utama → surat → kelas → nota → Aynaa → Hakim → Mei Ling → perpustakaan → pustakawan → 5/5 petunjuk → papan bukti → deduksi → KES 001 SELESAI.

Turut lulus:
- Pilihan objek salah memaparkan maklum balas; bantuan 0/3 → 1/3 → 2/3 → 3/3.
- Papan bukti kosong ditolak; ketiga-tiga hubungan betul diterima.
- Deduksi salah ditolak; teori betul menyelesaikan kes.
- Refresh memulihkan 5/5 petunjuk, tiga pilihan hubungan dan Bunyi: Mati.
- Keputusan dengan tiga bantuan: 2 bintang / 120 XP; replay bermula 0/5 dan rekod terbaik kekal.
- Fail Kes memaparkan lima petunjuk; Kembali, Agensi dan pautan jenama berfungsi.
- Klik tetikus pada kad KES 001 dan aktivasi papan kekunci Enter diuji.
- Tiada ralat JavaScript dalam log pelayar semasa ujian.
- `node --check game.js`, `node test-game.cjs` dan `git diff --check` lulus.
- Perbandingan dengan HEAD mengesahkan state/schema simpanan, bunyi, task, hint, validasi dan event handler tidak diubah.

Had QA: sentuhan peranti fizikal dan pendengaran output bunyi tidak diuji secara berasingan. Sasaran sentuhan minimum 44–48px dan kawalan HTML asli dikekalkan. Aliran penuh diuji sekali merentasi saiz telefon/desktop, bukan satu ulangan penuh pada setiap saiz.

## Perbezaan visual yang disengajakan
Ilustrasi SVG lebih ringkas daripada render terperinci North Star. Tiada meja kayu, tekstur berat, animasi watak atau hotspot berilustrasi baharu. Ikon objek kelas sedia ada dikekalkan. Struktur panel, warna dan keutamaan visual diterjemahkan kepada HTML/CSS responsif.

# v2.10.0 — Pelaksanaan C023

## Pengalaman bersepadu

C023, **Misteri Buku Panduan Berbelit**, berlaku di Perpustakaan Bayuraya. Mei Ling menemukan dua versi buku panduan yang belum konsisten. Cikgu Farah membantu pemain menggunakan sumber bahasa, sementara KLU membimbing penyiasatan tanpa mendedahkan jawapan lengkap.

Aliran kes:

1. Baca briefing dan objektif.
2. Cari lima sumber dalam sebarang urutan.
3. Bandingkan draf asal dengan salinan semakan.
4. Sahkan enam pembetulan melalui Detektif Penyunting.
5. Bina tiga hubungan pada Papan Bukti.
6. Jawab dua deduksi.
7. Sahkan buku panduan dan lihat resolusi.

## Lima petunjuk

| P | Sumber | Peranan |
|---|---|---|
| P1 | Draf Buku Panduan | Mengekalkan enam bentuk salah yang disengajakan. |
| P2 | Lembaran Rujukan Bahasa | Menerangkan kata majmuk, kata sendi `di`, awalan `di-` dan ejaan standard. |
| P3 | Catatan Penyunting | Menandakan kategori yang perlu diperiksa tanpa memberikan semua jawapan. |
| P4 | Kad Jemputan Program | Mengesahkan tempat, aktiviti dan tujuan program. |
| P5 | Salinan Semakan Akhir | Menunjukkan pindaan awal tetapi kekal berstatus belum disahkan. |

Petunjuk hanya direkod sekali. Editor dan Lensa tidak menambah petunjuk rasmi.

## Detektif Penyunting

Dokumen asal dipaparkan sebagai teks HTML dengan enam token semantik berukuran sentuhan sekurang-kurangnya 44px. Pemain memilih token, memilih satu calon pembetulan, boleh membuka rujukan berkaitan, dan mengesahkan jawapan.

| ID | Asal | Disahkan | Prinsip |
|---|---|---|---|
| ED-01 | Aturcara | Atur cara | Kata majmuk |
| ED-02 | di adakan | diadakan | Awalan pasif `di-` |
| ED-03 | diruang bacaan | di ruang bacaan | Kata sendi nama `di` |
| ED-04 | di jemput | dijemput | Awalan pasif `di-` |
| ED-05 | disini | di sini | Kata sendi nama `di` |
| ED-06 | aktifiti | aktiviti | Ejaan standard |

Setiap pembetulan disimpan secara bebas. Pratonton akhir dibina daripada enam status pembetulan. Teks kanonik akhir:

> Atur cara Jelajah Bahasa telah disediakan. Sesi pembukaan akan diadakan di ruang bacaan Perpustakaan Bayuraya. Semua peserta dijemput berkumpul di sini untuk aktiviti pertama.

## Papan Bukti dan deduksi

- EB1: P1 + P5 membuktikan kedua-dua versi masih memerlukan pengesahan.
- EB2: P2 + P3 membuktikan pembetulan mesti berdasarkan peraturan.
- EB3: P1 + P4 + P5, bersama enam pembetulan, membuktikan maksud program dikekalkan.
- D01: Draf asal belum disunting sepenuhnya.
- D02: Gunakan salinan akhir yang disahkan tanpa mengubah maksud.

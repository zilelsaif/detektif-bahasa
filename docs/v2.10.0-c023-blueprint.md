## Detektif Penyunting

Aliran: **Baca → Tandakan → Rujuk → Betulkan → Sahkan**.

Enam token sasaran:

1. `aturcara` → `atur cara`
2. `di adakan` → `diadakan`
3. `diruang bacaan` → `di ruang bacaan`
4. `di jemput` → `dijemput`
5. `disini` → `di sini`
6. `aktifiti` → `aktiviti`

P1–P5 diperlukan sebelum ruang penyunting dibuka. Setiap pembetulan disimpan secara bebas. Pratonton akhir dibina daripada status enam pembetulan, bukan dipaparkan sebagai jawapan automatik.

## Papan Bukti

- EB1: P1 + P5 — kedua-dua salinan belum disahkan.
- EB2: P2 + P3 — pembetulan ditentukan melalui peraturan bahasa.
- EB3: P3 + P4 + dokumen lengkap — maklumat program dikekalkan.
